# Currency Cards Dashboard

Одностраничное приложение на React и TypeScript: авторизация, таблица валют с динамикой курсов и создание карточек.

## Для входа в личный кабинет используйте демонстрационные данные:
Демо: https://currency-cards.netlify.app/

Тестовые данные для входа:

- **Логин:** `user@gmail.com`
- **Пароль:** `user123`

Авторизация работает в демонстрационном режиме без собственного backend.

## Возможности

- Mock-авторизация без собственного backend: форма входа с валидацией, выход из аккаунта и защита приватных маршрутов.
- Таблица валют с флагами, курсами относительно USD и изменением за период.
- Просмотр исторической динамики выбранной валюты на графике с выбором периода.
- Создание и редактирование карточек с валидацией, предпросмотром и сохранением в браузере.
- Адаптивный интерфейс для desktop, tablet и mobile.
- Состояния загрузки и ошибки для запросов курсов.

## Маршруты

- `/login` — вход в приложение.
- `/rates` — таблица валют и история курса выбранной валюты.
- `/cards` — список сохранённых карточек.
- `/cards/new` — создание карточки.
- `/cards/:id/edit` — редактирование карточки.

После входа пользователь попадает в защищённую часть приложения. Данные авторизации и карточек хранятся на стороне клиента; серверная авторизация и отправка карточки на backend не реализованы, поскольку задание предусматривает mock-поведение.

## API курсов валют

Для получения актуальных и исторических курсов используется открытый API [Frankfurter](https://frankfurter.dev/), базовый адрес — `https://api.frankfurter.dev/v2`.

Приложение запрашивает курсы валют относительно USD и использует исторические значения для расчёта изменения и построения графика. Для длинного периода исторический ряд запрашивается с недельной группировкой, чтобы уменьшить количество точек.

Примеры используемых запросов:

```text
GET https://api.frankfurter.dev/v2/rates?base=USD&quotes=EUR,JPY
GET https://api.frankfurter.dev/v2/rates?base=USD&quotes=EUR&from=2026-10-01
GET https://api.frankfurter.dev/v2/rates?base=USD&quotes=EUR&from=2026-10-01&group=week
```

Точный набор параметров зависит от выбранной валюты и периода. Ответ API проверяется схемой Zod; сетевые ошибки, HTTP-ошибки и некорректный формат ответа обрабатываются приложением.

В таблице используются AUD, BRL, CAD, CHF, MXN, EUR, GBP и JPY. MXN используется вместо BGN, поскольку выбранный API больше не предоставляет данные для BGN после перехода Болгарии на евро.
